# Workspace integration

The research method is fully included in this skill. Project records, user evidence, host tools and mandatory workspace instructions remain external inputs; no sibling skill is needed to supply method or code.

## Existing repository or project

Read applicable project instructions, current lifecycle/state, approved brief, refinement record, relevant phase material and referenced latest answer/review. Reconcile stale metadata against saved work before repeating questions. Resume the user's selected action; a new project proceeds through intake into research, while a bare continuation offers a concise recap and next actions.

Respect project-specific data and domain constraints. Use the host's required source/probe/recording and lifecycle utilities where prescribed by its instructions; these are project integration hooks, not dependencies of the standalone research method. Do not invent ad hoc replacements for an existing authoritative register. Preserve original evidence, local IDs and parallel contributors' edits. Regenerate derived views using the project's established procedure.

Where required, save a discovery baseline before searching. After presenting the result, update source observations, yield/intervention views, lifecycle and affected references. Distinguish newly acquired evidence from cache reuse, duplicate leads, failed access and workflow documentation. Preserve substantive user steering and assess observed contributions without inventing outcomes. Never claim an independent reviewer was used by this solo workflow.

## Standalone or isolated assignment

Use the supplied approved question/brief, evidence constraints and output paths. Do not create a canonical exploration or load unavailable repository files. For a new unapproved question, retain this skill's intake and approvals. Keep the compact working note, original evidence/checked extracts, source provenance and final report in the permitted workspace. The exact assignment's filename wins; otherwise save a complete sourced `report.md` and return its path with the answer's scope and limits. Reuse an existing inventory; do not create a second authoritative source index.

A frozen-corpus task permits inspection and analysis of that corpus only. A live task retains full authorized search, fetch, downloads and data analysis. Neither authorizes external communication or purchases. Honor isolation and completion boundaries; finish local records without publishing experimental evidence into canonical research.
